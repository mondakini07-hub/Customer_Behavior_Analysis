# Customer Behavior Analysis

## 📌 Project Overview

This project was completed as part of the **Alfido Tech Data Analytics Internship**.

The objective of this project is to analyze customer transaction data to identify purchasing behavior, customer segments, retention trends, and churn risks using Python-based data analytics techniques.

The project includes complete data preprocessing, exploratory data analysis (EDA), customer segmentation using RFM and K-Means clustering, purchase pattern analysis, retention analysis, customer lifetime value (CLV), and business recommendations.

---

# 🎯 Objectives

- Clean and preprocess customer data.
- Perform exploratory data analysis (EDA).
- Analyze customer purchasing behavior.
- Identify customer segments using RFM analysis.
- Apply K-Means clustering.
- Analyze purchase patterns.
- Study customer retention trends.
- Analyze customer churn.
- Generate business recommendations.

- High-value customers contribute the highest revenue.
- Loyal customers purchase more frequently.
- Purchase behavior varies across different months.
- At-risk customers have higher recency values.
